## 🛡️ About This Project

This is a professional portfolio website showcasing the dual expertise of **Tushar Basak**. As a **Cybersecurity Analyst** and **Web Developer**, I specialize in SOC operations, penetration testing, and building secure, user-centric web applications. This portfolio demonstrates my ability to bridge the gap between robust security and modern web development.

### 🎯 Key Features

- **Responsive Design**: Optimized for all devices and screen sizes
- **Progressive Web App (PWA)**: Installable with offline capabilities
- **Secure By Design**: Implemented with security headers (CSP, HSTS) and secure coding practices
- **Themed UI**: Dynamic style switcher with HSL-based color themes
- **Performance Optimized**: Lazy loading, preloader, and optimized assets
- **SEO Optimized**: Enhanced with structured data/JSON-LD and meta tags


## 🔒 Security Features

- **Content Security Policy (CSP)**: Strict policy to prevent XSS
- **HSTS**: Strict-Transport-Security enforced
- **X-Content-Type-Options**: Prevents MIME type sniffing
- **X-Frame-Options**: Prevents clickjacking
- **Input Sanitization**: Client-side validation for forms
- **Security.txt**: RFC-compliant security contact path
